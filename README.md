# 🎮 Advanced Pacman Game

A fully functional, advanced Pacman game built with HTML, CSS, and JavaScript!

## Features

- Classic Pacman gameplay with smooth animations
- Multiple levels - advance by eating all dots
- 4 AI-powered ghosts with different behaviors
- Power pellets to turn the tables on ghosts
- Score system and lives
- Responsive controls (Arrow keys or WASD)
- Tunnel effect through screen edges
- Visual effects and retro arcade aesthetic

## How to Play

1. Open `pacman-game.html` in any modern web browser
2. Use Arrow Keys or WASD to move Pacman
3. Eat all dots to advance to the next level
4. Avoid ghosts or eat power pellets to chase them
5. Try to achieve the highest score possible!

## Game Controls

- **Arrow Keys** or **WASD** - Move Pacman
- The game automatically saves your progress through levels

Enjoy the game! 🎮
